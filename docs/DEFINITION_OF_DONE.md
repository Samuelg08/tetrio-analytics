# Definition of Done

Una tarea se considera terminada solo cuando:

- [ ] Cumple criterios de aceptación.
- [ ] Maneja estados de error, ausencia de datos y entradas inválidas.
- [ ] Añade/actualiza pruebas relevantes.
- [ ] Se ejecutaron las pruebas y se reportan resultados reales.
- [ ] No introduce secretos ni datos sensibles.
- [ ] Actualiza contratos/documentación si corresponde.
- [ ] Se revisó el diff.
- [ ] No rompe módulos existentes.
- [ ] Se puede reproducir la ejecución siguiendo el README.

Para tareas de ML:
- [ ] Procedencia y versión del dataset documentadas.
- [ ] Definición de etiqueta y variables documentada.
- [ ] Riesgos de data leakage evaluados.
- [ ] Baseline calculado.
- [ ] Métricas de test reales reportadas.
- [ ] Artefacto y versión del modelo registrados.
- [ ] No se describen explicaciones como causalidad.
